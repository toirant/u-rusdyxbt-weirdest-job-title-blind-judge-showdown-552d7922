An entry for the [make.fun](https://make.fun) competition
**Weirdest Job Title: Blind Judge Showdown**
(`u-rusdyxbt-weirdest-job-title-blind-judge-showdown-552d7922`).

## What it does

`main.ts` writes a single job title to `entry.txt` — the weirdest job
title it could think of. The title is 48 characters, inside the
competition's 1–60 character gate, and nothing else: no trailing
newline, no extra words.

> Professional Mourner for Other People's Goldfish

## Why this title

The judge weighs weirdness, strangeness against ordinary work, a twist
that lands on first read, sounding like a real job, and reading
instantly, in that order.

- **Real job:** professional mourners are really hired to grieve at funerals.
- **Specific twist:** the grief is for someone else's goldfish — a very small coffin, a stranger in black, on the clock.
- **Instant read:** 48 characters, one line, the picture lands at a glance.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output node main.ts
```

Node 22 or later, no dependencies. The program creates the output
directory if needed and writes `entry.txt` inside it, then exits.
It never removes the output directory itself.
